# nickcomeaux-site

Source for my personal site, live at https://nicholascomeaux.com.

Static HTML, no build step. Pages:
- `index.html` - landing page
- `resume.html` - web resume
- `system-architecture.html` - a plain-English plus technical write-up of an AI
  multi-agent automation system I architected

Deploy: any static host. Locally, open `index.html` or serve the folder
(`python3 -m http.server`).
